# 💰 Учет финансов - Статистика

Веб-приложение для анализа доходов и расходов из заметок TargetNote.

## 🚀 Использование

1. Откройте [https://ваш-username.github.io/finance-stats](https://ваш-username.github.io/finance-stats)
2. Загрузите файл с заметками (экспорт из TargetNote)
3. Приложение автоматически распарсит данные и покажет:
   - Общий баланс (доходы - расходы)
   - Накопления
   - Расходы по категориям с процентами
   - Доходы по категориям
   - Историю всех операций

## 📊 Функции

- **Автоматический парсинг** заметок в формате iOS Shortcuts
- **Визуализация расходов** — где вы больше всего тратите
- **Категории доходов** — откуда приходят деньги
- **История операций** — полный список с датами и комментариями
- **Адаптивный дизайн** — работает на телефоне и компьютере

## 📝 Формат данных

Приложение читает заметки в формате:

```
🟢 ДОХОД
📅 06.10.2026
💬 Зарплата
🏷️ Зарплата
💵 50000 ¤

🔴 РАСХОД
📅 06.10.2026
💬 Продукты
🏷️ Магазин
💸 3480 ¤

💰 НАКОПЛЕНИЯ
📅 06.10.2026
💬 Откладываю на отпуск
💵 10000 ¤
```

## 🛠️ Технологии

- HTML5
- CSS3 (градиенты, анимации)
- Vanilla JavaScript (без зависимостей)
- Полностью клиентская обработка (данные не уходят на сервер)

## 🔒 Безопасность

Все данные обрабатываются локально в браузере. Ничего не загружается на сервер. Ваши финансы остаются приватными.

## 📦 Установка на GitHub Pages

1. Создайте репозиторий `finance-stats`
2. Загрузите `index.html`
3. Включите GitHub Pages в Settings → Pages → Source: main branch
4. Готово! Сайт будет доступен по адресу `https://ваш-username.github.io/finance-stats`

## 📱 Интеграция с iOS Shortcuts

В команде "Учет финансов - Статистика" используйте URL:

```
https://ваш-username.github.io/finance-stats
```

Приложение откроется в браузере и предложит загрузить файл заметок.
